# IconTile

Product icon inside the Mel shape (Brand · 06 Iconography): `mel-icon-tile` fill, `mel-icon-ink` 5px round-cap glyph on a 120 grid, glyph area 76. `--dark` for Deep Teal panels (Teal 2 shape, Mint glyph).

**Markup:** `<span class="rds-icon-tile" data-glyph="campaigns"></span>`; glyphs: campaigns, design, crm, client-experience, documentation, compliance, commissions, calendar, voice, working, ask. Sizes 24 / 32 / 48 / 72.

- Use tiles in cards, menus of Mel products and empty states; use bare Lucide icons inside buttons and tables.
