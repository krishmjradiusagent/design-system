# portal_card

**JSON `type`:** `portal_card` · Mel Chat Templates v0.2.1.


The agent's client portal: address, Live chip, a title, and Open.

**Fields:** `data.url`, `data.badge`, `data.title`, `data.actions[]` (Open, secondary, open_url).
**Colours:** the thumbnail and favicon use the **agent's own brand** (`--agent-brand`, `--agent-accent`), not Mel's. The navy and gold here are a sample.
