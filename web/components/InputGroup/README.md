# InputGroup

An input with icons, text or a button attached inside one stroke.

**Markup:** `.rds-input-group` > `.rds-input-group__addon` + bare `<input>` (+ optional `.rds-btn--sm`). `__addon--fill` gives a muted prefix/suffix block.

- Do use for search, URLs, units and inline submit.
- Don't stack two buttons inside.
