# MediaViewer

**Web only · not in Mel Chat Templates yet.** Built from the Mel web boards; the backend needs a template type before apps can send it.

The media viewer panel for marketing pieces (Mel web `.g-view`, `.v-view`). It has a Cloud background, a thumbnail strip on the left, the large piece with a soft shadow, the caption and tags, and previous/next.

**Top:** channel and position, "Open in Design Studio" (outline), Share, Close.
**Opens from:** a asset_package_card or a piece's expand button. The source card shows `aria-pressed="true"` while it is open.
