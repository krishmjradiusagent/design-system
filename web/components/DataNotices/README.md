# DataNotices

**Web only · not in Mel Chat Templates yet.** Built from the Mel web boards; the backend needs a template type before apps can send it.

Notices for data pages (Leaderboard edges: shared view, partial data, rank change).

- `.rds-dnotice--private`: Cloud with a Mint Pale border and a lock. Shown when a page is shared down to an agent.
- `.rds-dnotice--warn`: amber. Say what is missing and what to do.
- `.rds-dnotice--ok`: Mint Mist insight, bold first line.
- The panel status strip with `data-state="warn"` repeats the warning at the top of the panel.
