# MelMascot

Mel with eyes: the product mascot used in the Mel web chat and assistant picker (ported from `mel-mascot.css`). Same silhouette, white eyes that blink every 6s; `thinking` looks side to side, `done` smiles, `offline` goes Slate and sleepy.

**Markup:** `<span class="rds-mascot" data-state data-assistant></span>`; sizes `--inline` 26 · default 40 · `--hero` 64. Decorative: `aria-hidden` is set.

- Use the mascot inside product chat and pickers; use the Mel mark for logo, nav and status.
