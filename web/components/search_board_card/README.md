# search_board_card

**JSON `type`:** `search_board_card` · Mel Chat Templates v0.2.1. Replaces the legacy `search_board` action.

**Fields:** `data.id`, `data.title`, `data.subtitle`, `data.rows[]`, `data.link`.
**Note:** hand-authored in the CRM card style; no Mel web board yet.
