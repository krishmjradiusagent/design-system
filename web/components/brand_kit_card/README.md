# brand_kit_card

**JSON `type`:** `brand_kit_card` · Mel Chat Templates v0.2.1.


A sample design in the agent's colours, editable primary and accent colour chips, and the logo. The colour chips wrap a native colour input; changing a colour updates the sample.

**Markup:** `.rds-mc` > `.rds-brandprev` (`__top`, `__tag`, `__logo`, `__bar`, `__addr`) + `.rds-bchips` > `label.rds-bchip` (`.rds-bchip__dot` + `input[type=color]`).
