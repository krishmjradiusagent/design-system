# DropdownMenu

Action menu from a button. 8px items, 14px text, Slate icons, Mint Mist hover, `menu__shortcut`, checkbox items with a Green Text check, Danger items in `destructive`.

**Markup:** `[data-rds-root][data-rds-floating]` > trigger `[data-rds-trigger][aria-haspopup=menu]` + `.rds-menu.rds-floating[role=menu]` > `.rds-menu__label`, `.rds-menu__item[role=menuitem|menuitemcheckbox]`, `.rds-menu__sep`.
