# social_post_review_card

**JSON `type`:** `social_post_review_card` · Mel Chat Templates v0.2.1.

One channel's ready-to-publish pieces (Marketing skill · Instagram, Facebook, Email; Mel web `.m-draft`).

**Anatomy:**
- Channel tile and title, plus pieces count and account.
- Horizontal rail of 168px pieces: 4:5 image, expand button, 2-line caption, hashtags in info blue.
- Foot: when it posts, plus one pill.

**Email:** use `email_review_card`.
**States:** `data-state="sending|done"`; the pill becomes "✓ Posted". Placeholders stay in [BRACKETS] until the agent fills them.
