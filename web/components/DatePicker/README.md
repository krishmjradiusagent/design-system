# DatePicker

A Select-style trigger that opens a Calendar in a popover (shadcn Date Picker).

**Markup:** `.rds-select[data-rds-root][data-rds-floating]` with a trigger (leading `calendar` icon) and `.rds-floating` holding a `.rds-calendar`.

- Do format as "Sat, Nov 14, 2026"; never ambiguous numeric dates.
