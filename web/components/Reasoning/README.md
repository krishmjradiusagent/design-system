# Reasoning

Collapsible view of Mel's reasoning (AI Elements Reasoning). Slate trigger "Thought for N seconds", content indented with a 2px `border` rule. Auto-collapse once the answer starts.

**Markup:** `.rds-reasoning[data-rds-root]` > `.rds-reasoning__trigger[data-rds-trigger]` (with `.chev`) + `.rds-reasoning__content`.
