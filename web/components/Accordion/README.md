# Accordion

Stacked disclosures (Brand · 09 FAQ). 15px semibold triggers, chevron rotates, 1px dividers.

**Markup:** `.rds-accordion[data-rds-accordion="single"]` (omit `single` for multiple) > `.rds-accordion__item[data-rds-root]` > `.rds-accordion__trigger[data-rds-trigger]` + `.rds-accordion__content`. `data-open` opens an item.
