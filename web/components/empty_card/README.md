# empty_card

**JSON `type`:** `empty_card` · Mel Chat Templates v0.2.1.


Nothing to show yet, plus one line on what will appear. It is usually followed by `suggested_prompts` ("Start a campaign").

**Fields:** `data.title`, `data.text`.
**Markup:** `.rds-mc.rds-mc--empty` > `.rds-mc__t` + `.rds-mc__m`. It fits its content, with a 360px minimum.
**Copy:** state the fact ("No buyer activity this month"). No "Oops", no apology.
