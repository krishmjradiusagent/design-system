# Avatar

A person's photo or initials. Initials sit on Mint Mist in Green Text by default; `--sky` and `--dark` for variety. Sizes `sm` 24 · default 32 · `lg` 40 · `xl` 56.

**Markup:** `<span class="rds-avatar">JR</span>` or with `<img alt>`. `.rds-avatar__status` adds the live dot. `.rds-avatar-group` overlaps with a white ring.

- Don't use gradient avatars; initials or photos only.
