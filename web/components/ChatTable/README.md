# ChatTable

**Web only · not in Mel Chat Templates yet.** Built from the Mel web boards; the backend needs a template type before apps can send it.

A table inside a Mel reply (Mel web `.g-tbl`; MEL chat · Table in chat).

**Small (≤ 5 rows):** just the table. Cloud header row 13/600, 14/20 cells, numbers right-aligned and tabular, first column 500.
**Large:**
- Header bar with table icon, title and row count, plus an expand button.
- Body capped at about 6 rows with a sticky header and horizontal scroll.
- "Show all N rows" footer.
- Expand or "Show all" opens Table view in the right panel.

**Rules:**
- Max width 720px (the chat column).
- No zebra stripes; Cloud hover only.
- No more than 7 columns in chat; put the rest in the panel.
