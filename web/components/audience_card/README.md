# audience_card

**JSON `type`:** `audience_card` · Mel Chat Templates v0.2.1.


Who a campaign will reach: a segment line, then counts for matching, email-ready, text-ready and excluded contacts.

**Fields:** `data.title`, `data.subtitle`, `data.rows[]{label, value, tone?}`. Rows with a tone show a chip: info for email, success for text, warning for excluded.
