# RadioGroup

Single choice from a short list. 16px ring, Mel Green dot (Mel web `.w-radio`).

**Markup:** `role="radiogroup"` wrapper with `aria-label`; each `<label class="rds-choice">` holds `<input type="radio" class="rds-radio">`. `rds-choice--card` gives the bordered row; the checked card turns Mel Green stroke on Cloud (Mel web `.w-dest .w-rrow.on`).

- Do use for 2–5 options; more goes in a Select.
