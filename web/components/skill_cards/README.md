# skill_cards

**JSON `type`:** `skill_cards` · Mel Chat Templates v0.2.1.


Mel's opening list of what it can help with. Each card shows a skill-coloured Mel mark and one line. **Tapping fills the composer** with the card's `prompt`; it never sends.

**Fields:** `data.cards[]{skill, icon, text, prompt}`.
**Skill colours** (Mel mark shape only; the dot stays white): crm #0FA3B1 · marketing #EE6A4C · campaign #E9A320 · client #E0588A · compliance #4479B3 · document #9C6B4F · mls #8B6BC8.
**Layout:** 3 columns, min height 96, 16px radius, 14.5/600. Max 6 cards.

Try it: tap a card.
