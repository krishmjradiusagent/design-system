# Tabs

Switch between views. Default is the pill segmented control (white pill with `shadow-xs` on Cloud); `rds-tabs--line` is the underline variant (2px Deep Teal) for page-level tabs.

**Markup:** `.rds-tabs` > `.rds-tabs__list[role=tablist]` > `.rds-tabs__trigger[role=tab][aria-controls]` + `.rds-tabs__panel[role=tabpanel]`. Arrow keys move between tabs.
