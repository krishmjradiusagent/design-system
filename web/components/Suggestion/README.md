# Suggestion

Follow-up prompts after a Mel turn (Mel web `.g-row`, c-prompt-row). A `↳` text row in Slate, Cloud hover. **Tap fills the composer, it does not send** (`bundle.js`); `data-prompt` sets the filled text when it differs from the label.

**Variants:** rows (default, stacked; `--wrap` to flow) and `--chip` (outlined pills for empty-chat starters).

- Do offer 2–3, phrased as the agent would type them.
