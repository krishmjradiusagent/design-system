# Sonner

Toast notifications (shadcn Sonner). Bottom-right stack, 360px, `radius-xl`, `shadow-lg`, 4s auto-dismiss.

**API:** `RadiusUI.toast({title, description, variant: 'success'|'danger'|'warning'|'dark', action, duration})`, or `data-rds-toast="Title"` on a button. `--dark` (Deep Teal) is for Mel's own news.

- Do offer Undo for reversible sends. Don't stack more than 3.
