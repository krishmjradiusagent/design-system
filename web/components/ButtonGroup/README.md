# ButtonGroup

Joins related buttons into one pill. Ends round, middles square.

**Markup:** `<div class="rds-btn-group" role="group" aria-label="…">` around `.rds-btn` children of one variant. `rds-btn-group--sep` adds a 1px gap for split buttons (Send now + schedule menu).

- Do use for 2–4 closely related actions or a split button.
- Don't mix variants inside one group.
