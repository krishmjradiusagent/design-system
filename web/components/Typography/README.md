# Typography

Long-form text styles (shadcn Typography). Wrap content in `.rds-prose`: h1 36, h2 24 with a rule, h3 20, body 15/24, `.lead` 20 Slate, Green Text links, quiet blockquote, inline `code` on `muted`.

Type classes from tokens are also available anywhere: `.ui-h1`…`.ui-label`, `.brand-display`…`.brand-label`.
