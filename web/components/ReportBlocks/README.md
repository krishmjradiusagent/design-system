# ReportBlocks

**Web only · not in Mel Chat Templates yet.** Built from the Mel web boards; the backend needs a template type before apps can send it.

Blocks for pages Mel builds (leaderboard, year to date, insights; Mel web `.lb-page`). The page is 760px max, sits in the right panel, and is numbers-first with tabular figures.

**Blocks:**
- Head: eyebrow, H1 26/650, meta with a "From Radius" source pill.
- Hero: Deep Teal gradient, 44px figure, mint trend, 2×2 KPIs.
- Section: 18px radius, 15/650 title, Slate sub.
- Goal: ring, track with pace marker.
- Rankings: medals 1–3, bar track, delta ▲▼–, segmented filter.
- Funnel: Deep Teal to Mel Green steps.
- Donut and legend.
- Stat row.
- Insight note.
- Foot: "Built by Mel from Radius · As of …".

**Rules:**
- Every page names its source and date.
- Top performer bar uses `--gradient-signal`; the rest use soft lagoon #7ccfc0.
- No red unless the value went down.
