# AssistantPill

Assistant identity: the Mel mark in the assistant's accent + its name in a matching pill (Brand · 10 Assistants). Coral = Marketing Design, Lagoon = CRM, Honey = Campaign, Rose = Client Experience, Harbor = Compliance, Cocoa = Documentation. Mel Copilot keeps Mel Green on Mint Mist.

**Markup:** `.rds-assistant-pill[data-assistant]` > `.rds-mel-mark[data-assistant][data-still]` + name. Pill text tokens pass 6:1.

- Do use an accent only for its own assistant. Never two assistant colours in one place; never for buttons, body text or backgrounds.
