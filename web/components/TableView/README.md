# TableView

**Web only · not in Mel Chat Templates yet.** Built from the Mel web boards; the backend needs a template type before apps can send it.

Full table in the right panel (MEL chat · Table view). The chat keeps the collapsed table card; the panel shows every row with a sticky header and both-axis scroll.

**Panel top:** table icon, title, row count, Download CSV, Close.
**Motion:** the panel slides in 16px and fades over `--duration-reveal` 360ms with Mel ease.
