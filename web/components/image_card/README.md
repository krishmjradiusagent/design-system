# image_card

**JSON `type`:** `image_card` · Mel Chat Templates v0.2.1 · legacy `image` (design pending on the templates page).

**Status:** Mel-style design approved by KJ on 2 Nov 2026. There is no Mel web board for it yet.


One image with a 14px radius and a Line hairline, max 360px wide. **Tap opens the Media viewer**; the expand button does the same. It keeps the image's own aspect ratio (4:3 shown).
**Markup:** `.rds-imgcard` > `.rds-ph` (or `img`) + `.rds-ph__exp`.
