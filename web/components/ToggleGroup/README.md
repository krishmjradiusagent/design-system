# ToggleGroup

A set of toggles. Two looks: the pill segmented control (`.rds-toggle-group`, white pill on Cloud) and choice pills (`.rds-pill`, Mel web `.w-pill`: Mint Mist + Mel Green stroke when on).

**Markup:** add `data-rds-single` on the wrapper for single-select; omit for multi-select.

- Do use pills for filters and channel picks inside Mel cards.
