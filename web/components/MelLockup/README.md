# MelLockup

Primary lockup: Mel Green mark + lowercase **mel** wordmark in Deep Teal (Mona Sans 600, −0.045em). On Deep Teal the wordmark turns white (`--on-dark`); on Cloud or the Morning gradient it stays Deep Teal.

**Markup:** `.rds-mel-lockup` > `.rds-mel-mark` + `.rds-mel-lockup__word`. Set the word size so the mark height ≈ word size. Minimum lockup width 80px. In the app sidebar it is 26px mark / 20px word (`.rds-sidebar__brand`).
