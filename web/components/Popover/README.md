# Popover

Floating panel anchored to a trigger for small forms and pickers. `popover` surface, `radius-xl`, `shadow-md`, 16px padding, pops 150ms.

**Markup:** `[data-rds-root][data-rds-floating]` (position: relative) > `[data-rds-trigger]` + `.rds-popover.rds-floating` (`--end`, `--top` to re-anchor). Closes on outside click and Esc.
