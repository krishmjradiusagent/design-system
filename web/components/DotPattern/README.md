# DotPattern

The one Mel pattern (Brand · 04): a 12px dot grid, 1.4px dots, one colour at low opacity. `.rds-dots-bg` = Deep Teal 12% (on White or Cloud). On Mint Mist use Mel Green 22%; on Deep Teal use Mint 24%.

- Do fade or crop it to part of a surface. Don't enlarge dots, mix colours or layer it.
