# Badge

Small status or category label. Pill by default; `rds-badge--square` (6px) for counts in dense tables.

**Variants:** default (Cloud), `primary`, `outline`, `brand` (Mint Pale), status `success` · `warning` · `info` · `danger`, tags `teal` · `terracotta` · `iris` · `plum` · `sage`. `rds-badge__dot` adds a leading dot. `.rds-label-pill` is the brand eyebrow pill (uppercase, Mint Pale).

- Do pair status colour with a word; every tone passes 4.5:1.
- Don't invent badges to decorate; one badge per row cell.
