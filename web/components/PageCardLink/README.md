# PageCardLink

**Web only · not in Mel Chat Templates yet.** Built from the Mel web boards; the backend needs a template type before apps can send it.

A generated page, shown in chat as a card that opens in the right panel (Leaderboard skill; Mel web `.lb-cardlink`).

**Anatomy:**
- Deep Teal gradient thumbnail with up to 3 KPIs and a mint sparkline.
- Body: icon tile, title, scope, and an "Open" pill (it reads "Viewing" with a Mint Mist fill while open).

**Partial data:** an amber "N months missing" badge on the thumbnail plus a warn bar in the page.
**After it:** follow-up chips ("Only October" changes the page by asking).
**Context chip:** `.rds-ctx-chip` sits above Mel's answer when the question came from the panel's ask box.
