# Chart

Chart container (shadcn Chart): card, dashed `mel-line` grid, 11px Slate axis labels, legend with 10px swatches. Series colours are `chart-1`…`chart-5` (shadcn defaults; Mel has no chart palette).

- Do label series directly or with a legend; never rely on colour alone.
- Bring your own chart library; style it with these tokens.
