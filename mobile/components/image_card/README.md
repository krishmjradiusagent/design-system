# image_card

One image at full card width, keeping its own aspect ratio (4:3 shown).

**Source:** no mobile design on the templates page yet. Adapted from the Radius UI web design for `image_card` (legacy `image`); approved by KJ, 2 November 2026.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Tap:** opens the full-screen media viewer (pinch to zoom, swipe down to close, share). The expand button does the same.
