# portal_status_card

Where the client portal stands: title, one line, status badge (Not built, Building, Live).

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `portal_status_card`. Web twin: Radius UI `portal_status_card`.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Fields:** `data.title`, `data.subtitle`, `data.badge{text, tone}`.
