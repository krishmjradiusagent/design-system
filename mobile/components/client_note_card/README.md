# client_note_card

Confirms Mel saved a note. Row 1: pencil tile, caption "Created a note · client", chevron on the right. Below, full width from the card edge: note title and a 2-line preview. The whole card is the tap target and pushes the client page scrolled to the note.

**Source:** no mobile design on the templates page yet. Adapted from the Radius UI web design for `client_note_card` (legacy `client_note`); approved by KJ, 2 November 2026.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Layout:** header row + full-width body (changed by KJ, 2 November 2026).
