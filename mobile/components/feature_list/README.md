# feature_list

A plain list of what something does, grouped by audience: bold heading with an emoji, one line, one secondary line. No card chrome; it reads as Mel's reply.

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `feature_list`. Web twin: Radius UI `feature_list`.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Emoji:** kept as the template has them (headings only).
