# web_sources

Sources under an answer: up to five overlapped site icons in one pill, "Sources", "+N more". Tap opens a bottom sheet listing every source.

**Source:** no mobile design on the templates page yet. Adapted from the Radius UI web design for `web_sources` (legacy `google_search`); approved by KJ, 2 November 2026.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Site icons:** each site's favicon in a circle; without one, the first letter on an info tint. No brand logos drawn.
**Row tap:** opens the page in the in-app browser (SFSafariViewController / Custom Tab).
