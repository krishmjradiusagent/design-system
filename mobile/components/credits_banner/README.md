# credits_banner

Shown when an action needs credits the agent doesn't have: what is blocked, when credits renew, a used meter, and View billing.

**Source:** no mobile design on the templates page yet. Adapted from the Radius UI web design for `credits_banner` (legacy `insufficient_credits`); approved by KJ, 2 November 2026.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**View billing:** pushes the billing page (deep link). Warning tone means blocking, not an error. No apology in the copy.
