# empty_card

Nothing to show: a title and one line. Mel follows it with prompt rows.

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `empty_card`. Web twin: Radius UI `empty_card`.
**Alias page.** Built from existing parts: `m-crm-card` with a title and one meta line. No new styles; this page exists so the JSON type name maps one to one.

**Fields:** `data.title`, `data.subtitle`. No icon, no button.
