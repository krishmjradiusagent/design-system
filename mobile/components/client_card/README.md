# client_card

A compact pointer to a client. The whole card is the tap target and pushes the client page.

**Source:** no mobile design on the templates page yet. Adapted from the Radius UI web design for `client_card` (legacy `client`); approved by KJ, 2 November 2026.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Use `contact_card`** when Mel shows details; this card only points to a client.
