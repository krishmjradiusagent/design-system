# suggested_prompts

Prompt rows under a reply or in an empty chat. Tap fills the composer; it never sends.

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `suggested_prompts`. Web twin: Radius UI `suggested_prompts`.
**Alias page.** Built from existing parts: `c-prompt-rows` > `c-prompt-row` (see PromptRow). No new styles; this page exists so the JSON type name maps one to one.

**Styles:** standard · `--more` · `--destructive`.
