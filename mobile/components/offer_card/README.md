# offer_card

Points to an offer. Row 1: file tile, caption "Offer documents for client", chevron on the right. Below, full width: the property address. The whole card pushes the offer page.

**Source:** no mobile design on the templates page yet. Adapted from the Radius UI web design for `offer_card` (legacy `offer`); approved by KJ, 2 November 2026.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Layout:** header row + full-width body, same as `client_note_card` (KJ, 2 November 2026).
**Fields today:** client name and property address only; price and terms are not invented.
