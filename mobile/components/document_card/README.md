# document_card

A file Mel produced or found: page thumbnail, name, type, size, pages, and Preview.

**Source:** no mobile design on the templates page yet. Adapted from the Radius UI web design for `document_card` (legacy `file`); approved by KJ, 2 November 2026.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Preview:** opens the native full-screen document viewer (iOS QuickLook / Android PDF viewer) with share; not a side panel.
