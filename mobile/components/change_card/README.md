# change_card

Before → after review for a CRM update. Old value struck through in secondary text, new value in primary. Unchanged fields say "no change".

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `change_card`. Web twin: Radius UI `change_card`.
**Native rules:** the card sits in the chat column at full width. A link row pushes a full page (iOS push / Android new screen), never a side panel or popover. Tap targets are 44pt on iOS and 48dp on Android.

**Flow:** Mel asks "Save it?" with prompt rows "Save it" and "Change something". After saving, the status line "Saved to Radius CRM" replaces the question.
**Saved state:** added from the web design (the template shows the review only). Approved by KJ, 2 November 2026.
