# mel_text

Mel's plain reply: no card, no bubble. Paragraphs, bold, lists.

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `mel_text`. Web twin: Radius UI `mel_text`.
**Alias page.** Built from existing parts: `c-ai-message--assistant` + `c-streaming-text c-mel-plain` (see MelChat and StreamingText). No new styles; this page exists so the JSON type name maps one to one.

**Stream:** one word every 55–60ms; reduced motion shows it at once.
**Small fix:** the template's exclamation mark and emoji are dropped from the sample copy (house rule).
