# website_review_card

A property website to approve: head with Copy link, one 16:9 preview, then Publish.

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `website_review_card`. Web twin: Radius UI `website_review_card`.
**Native rules:** full width in the chat column. No side panels or popovers: previews open a full-screen viewer (pushed page), lists and choices open a bottom sheet. Tap targets 44pt iOS / 48dp Android.

**Behaviour:** expand pushes a full-screen page that scrolls the whole site. Copy link copies and shows a toast "Link copied". Publish follows the card protocol (sending → done "Live").
