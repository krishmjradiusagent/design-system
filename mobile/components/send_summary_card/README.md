# send_summary_card

One-line result after a send: icon, what happened, per-channel counts. Warning variant when some failed.

**Source:** Mel Chat Templates v0.2.1, mobile design for JSON `type` `send_summary_card`. Web twin: Radius UI `send_summary_card`.
**Native rules:** full width in the chat column. Detail pushes a full page, lists and choices open a bottom sheet; no side panels or popovers. Tap targets 44pt iOS / 48dp Android.

**Next:** failures are followed by a prompt row ("Fix the 8 failed invites").
